# ✈️ AWC

> A modern digital restaurant menu and ordering website designed to provide customers with a fast, seamless, and mobile-friendly dining experience.

The Air Warrior Club website replaces traditional printed menus with an interactive digital menu that allows customers to browse dishes, view prices, explore categories, and place orders with ease. The platform is optimized for speed, responsiveness, and an intuitive user experience.

---

## ✨ Features

- 🍽️ Digital Restaurant Menu
- 📱 Mobile-First Responsive Design
- 🖼️ High Quality Food Images
- 🔍 Instant Menu Search
- 🗂️ Category-wise Food Browsing
- 💰 Dynamic Pricing Display
- ⚡ Fast Loading Performance
- 📞 Quick Contact & Order Options
- 🌐 SEO Optimized Pages
- 🎨 Clean & Modern UI
